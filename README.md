# MMS Content Archive

An **unofficial, community-made** archive that summarizes and categorizes the session content of past
MMS (Midwest Management Summit) editions, built from their public [Sched](https://sched.com) schedules.

This project is not affiliated with or endorsed by MMS. Session materials are linked to their original
location on Sched, not re-hosted.

## What it is

A public, browsable, searchable static site that ingests the public Sched schedule of multiple MMS
Editions, normalizes them into a consistent model, assigns each Session a curated Category, and lets
visitors search by topic and filter by Edition, Category, and Speaker.
